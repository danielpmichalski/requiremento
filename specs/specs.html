Specification

This page shows and edits a requirements specification, for example specs/LIB-101.json. Opened directly from disk, the browser can't read that file by itself, so pick it once. Then load terms/terms.json too, so the page can show and check the terms.

Served by a web server, open specs.html?spec=LIB-101.json.

Your browser can't save files directly. You can read and edit here, then download the result and replace the file. Chrome and Edge save directly.
